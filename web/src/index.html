Troubleshooting
  • If compilation fails, check the end of the log and the error locations in the source.
  • If TeX or SyncTeX is missing, open Settings to check the TeX Live location and installation instructions.
  • If PDF navigation points to an old source position, save and compile the source again.

Editing and compilation settings

Autosave waits for compilation to finish. Drafts are recorded on this computer even when autosave is off.

Show commands, environments, citations, and cross-references. Environments can include their matching end.
