# Local TeX Web Editor 0.1.15

## Download files and choose where to save them

- The file list and Compiled PDFs context menus offer **Download** and **Save as…**. Download uses the browser's download settings; Save as opens the Windows or Mac save dialog to choose a folder and name, including confirmation before replacing a file.
- Files being edited export their current text, including unsaved changes. Saving to the original project file uses the normal external-change checks and edit history. Other files keep their original bytes.
- The PDF toolbar uses **Download** consistently, with **Save as…** in **PDF actions**.

## Restore browser tabs after restarting

- The app remembers its local connection address so browser tabs can reconnect after the process restarts.
- **Settings → Start at login → Enable start at login** makes the app available in the background after signing in to Windows or Mac. Restoring browser tabs opens the editor; if the app is still starting, a waiting page reconnects automatically.
- Start at login opens no additional browser tab. It can be disabled in Settings, and resetting settings also disables it. Operating-system startup choices are shown in the same section.
- An open tab notices an application update and offers to open the new screen after saving its text or recording a draft.
- After upgrading from v0.1.14 or earlier, open the new app once and use its new browser tab for future restores.

## Startup, editing and appearance

- PDF.js loads when a PDF is first opened. The math renderer is included once, reducing the JavaScript needed by the initial screen. Unchanged assets can be reused when the screen is opened again.
- Updating installed launch links runs after the editor opens. The Windows update checks the executable once before updating its existing shortcuts.
- Editing ordinary TeX text reuses bibliography information when it has not changed, avoiding repeated citation-index creation and PDF-link updates. Bibliography edits still update the displayed citation details.
- The initial accent and the application icons are blue. Previously chosen appearance settings continue to apply. **Settings → Appearance** can switch an existing installation to **Blue**.
- The website, READMEs and Store listing materials use the updated controls, descriptions and screenshots.

## 更新内容

### ファイルをダウンロードし，保存先を選ぶ

- ファイル一覧と「コンパイルした PDF」の右クリックに **「ダウンロード」** と **「名前を付けて保存…」** を追加した．ダウンロードにはブラウザの設定を使う．名前を付けて保存では Windows または Mac の標準の保存画面でフォルダーと名前を選び，同名のファイルがあれば上書きを確認する．
- 編集中のファイルでは，未保存の変更を含む現在の本文を出力する．元のプロジェクトファイルを保存先に選ぶと，通常の保存と同じ外部変更の確認と編集履歴の記録を行う．そのほかのファイルは元のバイト列で保存する．
- PDF の操作欄の名称を **「ダウンロード」** にそろえ，**「PDF の操作」** に **「名前を付けて保存…」** を追加した．

### 再起動後にブラウザのタブから戻る

- アプリが PC 内の接続先を記録し，起動し直した後もブラウザのタブから再接続する．
- **設定 → ログイン時の起動 → ログイン時の起動を有効にする** で，Windows または Mac へのログイン後にバックグラウンドで起動する．ブラウザで前回のタブを復元すると編集画面へ戻り，アプリの起動中は待機画面から自動的に再接続する．
- ログイン時に新しいブラウザのタブは開かない．設定から無効にでき，設定の初期化でも無効にする．OS の起動設定で確認が必要な場合は，同じ欄に案内する．
- 開いているタブでアプリの更新を確認すると，本文を保存するか草稿に記録して，新しい画面へ移る操作を表示する．
- v0.1.14 以前から更新した場合は，新版を一度開き，そのときに開いたタブを次回から復元する．

### 起動，編集，外観を改善する

- PDF.js は最初に PDF を表示するときに読み込む．数式の描画ライブラリの重複を解消し，初期画面に必要な JavaScript を減らした．画面を開き直す際は，変更されていないファイルを再利用する．
- 配置済みのアプリと起動用のリンクの更新を，編集画面を開いた後に進める．Windows の更新では，実行ファイルを 1 回確認してから既存のショートカットを更新する．
- 通常の TeX 本文を編集した際，変更がない文献情報を再利用し，引用の索引と PDF のリンク表示を繰り返し作り直す処理を減らした．文献を編集した場合は表示を更新する．
- 初期のアクセントとアプリのアイコンを青系へ変更した．保存済みの外観は引き続き使える．既存の設定を青へ変える場合は **設定 → 外観 → アクセント → 青** を選ぶ．
- サイト，README，Store の掲載用資料の操作名，説明，スクリーンショットを更新した．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．Microsoft Store 版は，対応する申請の公開後に更新できる．
