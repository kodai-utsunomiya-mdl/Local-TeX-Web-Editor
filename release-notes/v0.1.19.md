# Local TeX Web Editor 0.1.19

## 日本語

- ホームの各プロジェクトに **ZIP** メニューを追加した．最近開いたプロジェクトから，**プロジェクトを ZIP でダウンロード** と **ZIP にして名前を付けて保存…** を選べる．
- 編集中のプロジェクトを書き出すときは，原稿を保存してから ZIP を作る．別のプロジェクトは，そのフォルダーに保存されたファイルを書き出せる．
- **ログイン時の起動** の初期値を有効にした．PC へログインするとアプリがバックグラウンドで起動し，復元したブラウザのタブから編集を再開できる．設定からオン・オフを切り替えられる．

アプリの自動更新は初期状態で有効である．v0.1.17 以降はアプリが更新を確認する．v0.1.16 以前の ZIP 版を使っている場合は，新しい版を一度導入すると，以降の自動更新を利用できる．Store 版は，Store の審査と公開の完了後に更新できる．

## English

- Added a **ZIP** menu to each project on Home. Choose **Download project as ZIP** or **Save project ZIP as…** directly from the recent projects list.
- Exporting the current project saves edited documents before creating the ZIP. Other recent projects can be exported from their saved files.
- Enabled **Start at login** by default. The app starts in the background when you sign in, so restored browser tabs can reconnect. You can turn this setting on or off in Settings.

Automatic app updates are enabled by default. Version 0.1.17 and later can check for this update. Install a current version once when upgrading from a ZIP edition of v0.1.16 or earlier. The Microsoft Store edition becomes available after Store review and publication.
