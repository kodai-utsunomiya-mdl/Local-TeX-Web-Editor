# Local TeX Web Editor 0.1.10

## Write inline equations in Markdown

- **Insert math** now opens a dialog in both Visual editing and Source. Choose inline or display math, enter TeX, and check the rendered equation and the Markdown before inserting it.
- For inline math, choose GitHub's ``$`…`$`` notation, `$…$`, or `\(…\)`. The initial choice is the GitHub notation, and the dialog remembers the chosen form while the editor is open.
- Typing an inline equation in Visual editing converts it when the closing delimiter is entered. The saved Markdown uses the delimiter that was typed.

## Use Markdown shortcuts while editing visually

- A paragraph containing `---` becomes a horizontal rule when followed by `Enter` or a space.
- Equations and formatting shortcuts work next to Japanese text. Literal code and escaped delimiters remain editable as written.
- Input conversions work with Undo and Redo, and the toolbar follows cursor movement, text selection, and keyboard shortcuts.

## See the active formatting

- Formatting buttons show the marks and list or block style at the cursor, including formatting selected before typing the next character.
- A selection containing both formatted and plain text shows a mixed state.
- Image, Table, and New page use icon buttons with hover labels and accessible names.

## Format Japanese text and insert from the context menu

- Japanese italic and strikethrough text appears in the visual editor, preview, and printing, including combined marks and punctuation beside the marked text.
- Right-click in TeX or Markdown to insert images and tables at the clicked position or into the current selection. Markdown also offers linked pages, links, math, and code blocks in both modes.
- `Shift + F10` opens the insertion menu at the cursor. `Shift + right-click` opens the browser's context menu.

## Sort the file list

- Choose ascending or descending names, newest first, oldest first, or a manual order below **Find files**. Name and date sorting put folders first at each level; filtering follows the chosen order.
- Modification times come from the operating system for each file and folder. Saving updates the list immediately; refreshing it or returning to the tab reads external changes. The selected order is saved for later sessions.
- Drag between entries to switch to manual order and arrange them, or use `Alt + Up` / `Alt + Down`. Drop onto the center of a folder to move an entry into it. A move stops if that name already exists at the destination; open tabs and unsaved edits follow the moved path.

## Copy files and create them from templates

- **Create a copy…** copies a project file or folder to a destination you review. It copies the saved contents, and the original tabs remain available with their unsaved text.
- The new-file dialog offers an empty file or a built-in or custom template. Select one text file from a template, preview its contents, and choose its new path. The folder used to open the context menu is the initial destination.

## Find each document's compiled PDF

- **Compiled PDFs** in the file list shows each TeX document's latest successful PDF, with its actual output name and the path of its TeX document.
- Open an entry in the preview while keeping manuscript tabs in place. Its context menu also offers **Save PDF** and **Copy into project…**.
- Reopening a project restores the list. A failed or cancelled compilation leaves the previous successful result available.

## Follow changes made on your computer

- Home refreshes current and recent project folders and explains missing or unreadable locations. Check a folder again after restoring it, or remove its recent entry while leaving its files, settings, and drafts in place.
- If the current folder becomes unavailable, open text and drafts stay editable while saving to that folder and compiling pause. Cached PDFs remain available; restoring the folder allows work to resume.
- Refreshing also updates open documents without unsaved edits from disk. Documents with edits show a comparison, and a file deleted outside the app keeps its open text and draft until you choose whether to create it again.

## Read notifications and menus more easily

- Notifications and floating menus use their own background colors, stronger borders, and a visible shadow.
- Text, secondary labels, and highlighted items use readable colors in light and dark modes, including custom color schemes.

## Apply settings explicitly

- The editing and compilation dialog and the history settings form use **Save and apply settings**. Their success messages confirm that the saved settings have been applied.

## Update

Save your documents and quit the old app before opening the new version. Settings, drafts, and the TeX Live location carry over. Microsoft Store updates become available after the corresponding submission is published.

## 日本語

### Markdown にインライン数式を挿入する

- 直接編集とソース編集の両方で，「数式を挿入」から画面を開ける．インライン数式とディスプレイ数式を選び，TeX，表示する式，挿入する Markdown を確認して追加する．
- インラインの記法は，GitHub 向けの ``$`…`$``，`$…$`，`\(…\)` から選べる．初期値は GitHub 向けとし，エディタを開いている間は選んだ形式を次の挿入にも使う．
- 直接編集で数式の記法を入力すると，閉じる区切りを入力した時点で式へ変換する．保存する Markdown には入力した区切りを使う．

### 直接編集で Markdown の記法を入力する

- `---` だけの段落で `Enter` またはスペースを入力すると，横線へ変換する．
- 日本語に接して入力した数式や装飾にも対応する．コード内の文字や，エスケープした区切りも入力どおりに編集できる．
- 変換した内容は Undo と Redo で操作できる．カーソルや選択範囲の移動，キーボードからの装飾の変更もツールバーへ反映する．

### 有効な装飾を確認する

- カーソル位置で有効な装飾，リストやブロックの種類をボタンの表示へ反映する．文字を入力する前にボタンで選んだ装飾も表示する．
- 選択した文字の一部に装飾がある場合は，その状態も示す．
- 画像，表，新規ページはアイコンで表示し，カーソルを合わせると操作名を確認できる．

### 日本語の装飾と原稿の右クリック

- 日本語の斜体と取り消し線を，直接編集，プレビュー，印刷で表示する．複数の装飾や，前後に句読点がある場合にも対応する．
- TeX と Markdown の原稿で右クリックすると，画像と表を挿入できる．Markdown ではリンク付きの新規ページ，リンク，数式，コードブロックも選べる．クリックした位置か，選択中の範囲へ挿入する．
- `Shift + F10` でカーソル位置に挿入メニューを開く．`Shift + 右クリック` ではブラウザのメニューを開ける．

### ファイル一覧を並び替える

- 「ファイルを検索」の下で，名前の昇順・降順，更新日時の新しい順・古い順，手動の順序を選べる．名前や日時で並べる場合は各階層でフォルダーを先に表示し，検索結果も選んだ順序にする．
- 各ファイルとフォルダーの OS の更新日時を使う．保存した直後に一覧へ反映し，一覧の更新やタブへ戻ったときにも他のアプリでの変更を読み取る．選んだ並び順は次回も使える．
- 項目の間へドラッグすると手動の順序へ切り替え，`Alt + 上矢印` / `Alt + 下矢印` でも並び替えられる．フォルダーの中央へドロップするとその中へ移動する．移動先に同名の項目がある場合は止め，移動した場合はタブと未保存の本文も新しいパスへ移る．

### ファイルをコピーし，テンプレートから作成する

- 「コピーを作成…」でプロジェクト内のファイルやフォルダーをコピーできる．保存済みの内容をコピーし，元のタブでは未保存の本文を引き続き編集できる．
- 新規ファイルの画面で，空のファイルか標準・ユーザーのテンプレートを選べる．テンプレートからテキストファイルを 1 個選び，内容をプレビューし，作成先のパスを確認する．右クリックメニューを開いたフォルダーが最初の作成先になる．

### 文書ごとのコンパイルした PDF を開く

- ファイル一覧の「コンパイルした PDF」に，各 TeX 文書の最新の成功結果を表示する．実際の PDF 名と，コンパイル元の TeX のパスを確認できる．
- 一覧から開くと，原稿のタブをそのままにしてプレビューへ表示する．右クリックメニューには「PDF を保存」と「プロジェクトへコピー…」もある．
- プロジェクトを開き直したときにも一覧を読み戻す．コンパイルが失敗した場合や中止した場合は，前回成功した結果を引き続き開ける．

### PC 上の変更を読み直す

- ホームで現在と最近のプロジェクトの場所を読み直し，移動・削除や読取りの問題を表示する．フォルダーを戻した後に再確認でき，一覧から外しても原稿，設定，草稿は残る．
- 現在のフォルダーが使えない間も，開いた本文と草稿を編集できる．その場所への保存とコンパイルを止め，保存された PDF は引き続き読める．フォルダーが戻ると保存を再開できる．
- 未保存の編集がない原稿には，外部で変更された本文を読み込む．編集中の原稿は内容を比較でき，外部で削除された場合も本文と草稿を残し，確認してからファイルを作り直せる．

### 通知とメニューを読みやすくする

- 通知や浮動メニューの背景色と枠を調整し，影を強めた．
- ライトとダークの両方で，本文，補足，選択した項目の文字色を背景に合わせる．カラーコードで指定した配色にも対応する．

### 設定を保存して反映する

- 編集・コンパイルの設定と履歴の設定で，ボタンを「設定を保存して反映」に変更した．完了したときのメッセージにも，保存と反映の結果を表示する．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．設定，草稿，TeX Live の場所は引き続き使える．Microsoft Store 版は，対応する申請の公開後に更新できる．
