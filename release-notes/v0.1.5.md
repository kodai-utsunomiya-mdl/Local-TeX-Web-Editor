# Local TeX Web Editor 0.1.5

## Changes

- Windows now uses Per-Monitor V2 DPI awareness for native windows, including the project-folder picker.
- Added MSIX packaging for Microsoft Store distribution. The Store edition uses Windows installation and updates, and opens the editor in the browser.
- On the first Store launch, valid settings, view preferences and drafts from the ZIP edition are copied into the Store app's data folder. Project documents stay in their existing folders.
- The Store edition uses the Start menu entry created by Windows. TeX Live remains a separate installation selected in the editor's settings.

## Updating the ZIP edition

On Windows, extract the new ZIP and launch `local-tex-web-editor.exe`. If an earlier version is running, save your documents and close that version using the displayed instructions. Existing settings and installed shortcuts are used by the new version.

On macOS, save your documents and quit, replace the app in Applications with the new `.app`, and reopen it.

The app version appears at the lower right of the editor. Continue using the TeX Live installation already configured for your projects.

## 日本語: 変更した内容

- Windows のフォルダー選択画面などで Per-Monitor V2 を使い，ディスプレイごとの表示倍率に対応するようにした．
- Microsoft Store で配布するための MSIX を追加した．Store 版は Windows からインストール・更新し，ブラウザに編集画面を開く．
- Store 版の初回起動時に，ZIP 版の設定，表示位置，草稿を読み，Store 版のデータフォルダーへコピーする．原稿はこれまでのプロジェクトフォルダーで編集する．
- Store 版は Windows が作るスタートメニューの項目から起動する．TeX Live は別途インストールしたものを設定画面で選ぶ．

## 日本語: ZIP 版を更新する

Windows では新しい ZIP を展開し，`local-tex-web-editor.exe` を起動する．旧版が動いている場合は，表示された案内から原稿を保存して旧版を終了する．設定と作成済みの起動用ショートカットは新版でも使える．

macOS では原稿を保存してアプリを終了し，「アプリケーション」の `.app` を新しいものに置き換えて開く．

画面右下でアプリのバージョンを確認できる．TeX Live は，これまでプロジェクトで使っていたものを引き続き使う．
