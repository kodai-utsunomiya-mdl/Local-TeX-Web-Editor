# Local TeX Web Editor 0.1.7

## Writing across a project

- **Search project** or `Ctrl + Shift + F` searches supported text files across the project, including unsaved edits. Review each replacement, select the occurrences to change, and save them together. The app checks editor text and disk revisions before writing. Search supports multiline text, case matching, whole words, and RE2 regular expressions, with up to 1000 results and a cancel button.
- **Back** and **Forward**, also available through `Alt + Left` and `Alt + Right`, return to earlier source and preview locations. After following an internal PDF reference link, you can return to the passage you were reading. Outline, search, citation, reference, and SyncTeX navigation also work with these controls.
- **Editing tools → References and citations** shows definitions and uses of citation keys and labels, with excerpts and links to their source. A key rename includes a preview of the affected lines before saving.
- **Open two source editors** displays different documents or two parts of the same document. Each view has its own cursor and scroll position. Editing the same document updates both views, and Undo and Redo work from either one. Drag the divider to resize the views; narrow windows arrange them vertically.
- Open tabs and their order are restored with the project, together with the active editor, the two-editor layout, and source positions. Drag tabs to rearrange them.
- **Log** groups the remaining compilation errors and warnings into references, citations, overfull/underfull boxes, and other warnings. Items with a file and line number open that source location. After compilation, the list reflects the final TeX pass.

## Local edit history

**Editing tools → Document history** compares an earlier version with the current document and lets you restore selected changes. They return to the editor as an edit that can be undone. **Record current text** also records unsaved text with an optional version name.

History starts enabled and compresses the previous text when an edited file is saved, with at least one minute between automatic versions of a file. **History settings** in the same dialog changes the period and capacity or stops new records.

| Setting | Default or limit |
| --- | --- |
| Period | 30 days; adjustable from 1 to 365 days |
| Total storage | 50 MiB; adjustable from 5 to 200 MiB |
| Versions per file | 50 |
| Versions across all projects | 2000 |
| Document size for history | 2 MiB |

Older versions, including named versions, are removed when these limits are reached. History and custom templates use the app's local data folder. The English and Japanese privacy pages now describe these files and their controls.

## Figures, tables, and templates

- Paste an image, drop a file onto the editor, or choose **Editing tools → Insert an image**. PNG, JPEG, and PDF files are supported up to **8 MiB** each. Review the project destination and source before insertion. TeX figures can include a caption, label, and width; Markdown uses a relative image link or a link to a PDF.
- **Insert a table** accepts tab- or comma-delimited cells copied from a spreadsheet. Enter rows and columns to **Create a new table**, then edit the preview cells and insert TeX or Markdown. The limits are 500 rows, 50 columns, and 10,000 cells.
- **Create from a template** on the opening screen, or **Editing tools → Manage templates**, creates a project from a Japanese document, English article, Beamer slides, or Markdown notes. Add selected files from your own project as a custom template and edit its name and description later. Up to 20 custom templates can be registered, with 200 files and 32 MiB per template. Generated PDFs, auxiliary compilation files, and edit history are omitted.

## Markdown and appearance

- The Markdown editing toolbar adds headings, bold, italic, strikethrough, bullet and numbered lists, task lists, blockquotes, inline code, links, code blocks, and tables. Link and code dialogs show the information to insert, and the changes can be undone.
- **Sync scrolling** now works in both directions between the Markdown source and preview. It starts enabled and can be turned off to scroll the two independently.
- The initial appearance uses **Gray** and **Consolas** with system light/dark mode. Existing saved choices continue to apply. If Consolas is unavailable, the editor follows the existing Default font order through Cascadia Code, Menlo, DejaVu Sans Mono, and the browser's monospace font. Use **Settings → Appearance** to choose another appearance.
- Following an outline entry or double-clicking the PDF shows the corresponding source line near the top with space above it. The destination is briefly highlighted.

## Updating

For the Windows ZIP edition, save your documents and close any earlier version, extract the new ZIP, and open `local-tex-web-editor.exe`. Existing settings, drafts, and the configured TeX Live installation remain available.

On macOS, save your documents and quit, replace the app in Applications with the new `.app`, and reopen it.

Microsoft Store updates become available after the corresponding Store submission is published. Check the version at the lower right of the editor. The [README](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/blob/main/README.md) explains the new controls and storage limits; [v0.1.6](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/releases/tag/v0.1.6) records the previous release's changes.

## 日本語: プロジェクトを編集する

- 「全体を検索」または `Ctrl + Shift + F` で，未保存の内容も含めてプロジェクト内のテキストを検索できるようにした．変更前と変更後を見て箇所を選び，まとめて置換・保存できる．保存前にはエディタとディスク上の内容を確認する．複数行，大文字と小文字の区別，単語単位，RE2 の正規表現に対応し，検索結果は最大 1000 件で，中止ボタンも使える．
- 「戻る」「進む」，または `Alt + 左矢印` / `Alt + 右矢印` で，原稿とプレビューの移動前の位置へ戻れるようにした．PDF 内の参照リンクを開いた後も，読んでいた位置へ戻れる．アウトライン，検索結果，引用，相互参照，SyncTeX での移動にも使える．
- 「編集の操作 → 引用・参照を確認」で，引用のキーとラベルの定義・使用箇所を表示するようにした．本文の抜粋を確認して原稿へ移動でき，名前を変更する際には対象の行を確認してから保存できる．
- 「原稿を二つ並べる」で，別々の文書や同じ原稿の異なる箇所を編集できるようにした．各表示でカーソルとスクロール位置を動かせ，同じ原稿の変更は両方に反映する．どちらの表示からも Undo と Redo を使える．境界をドラッグして大きさを調整でき，狭い画面では上下に並ぶ．
- プロジェクトを開き直した際に，全てのタブと並び順，操作中だったエディタ，二つの表示の配置と位置を読み戻すようにした．タブはドラッグして並べ替えられる．
- 「ログ」で，コンパイルのエラー，相互参照，文献，本文のはみ出しなど，その他の警告を絞り込めるようにした．ファイル名と行番号がある項目を選ぶと原稿へ移動する．コンパイルの終了後は，最後の TeX の実行に残った項目を表示する．

## 日本語: 編集履歴

「編集の操作 → 編集履歴を開く」で，以前の版と現在の原稿を見比べ，選んだ箇所を戻せるようにした．戻した内容はエディタへ反映し，Undo で取り消せる．「現在の内容を記録」では，未保存の本文にも名前を付けて記録できる．名前は省略できる．

初期状態では記録をオンにし，原稿の保存時に変更前の本文を圧縮して記録する．同じファイルの自動記録には 1 分以上の間隔を設ける．同じ画面の「履歴の設定」で期間と容量を変更し，新しい版の記録を止めることもできる．

| 設定 | 初期値または上限 |
| --- | --- |
| 保存する期間 | 30 日．1〜365 日で変更できる |
| 合計容量 | 50 MiB．5〜200 MiB で変更できる |
| 1 ファイルの版数 | 50 版 |
| 全プロジェクトの版数 | 合計 2000 版 |
| 履歴に記録する原稿の大きさ | 2 MiB |

上限に達した場合は，名前を付けた版を含めて古いものから削除する．編集履歴と自分のテンプレートは，PC のアプリ用データフォルダーへ保存する．日英のプライバシーポリシーにも，保存する内容と操作方法を追記した．

## 日本語: 図，表，テンプレート

- 画像の貼り付け，ファイルのドラッグ，または「編集の操作 → 画像を挿入」から，PNG・JPEG・PDF を **1 個につき 8 MiB** まで取り込めるようにした．保存先と挿入する原稿を確認して進める．TeX では図の説明，ラベル，幅を指定でき，Markdown では相対パスの画像や PDF へのリンクを挿入する．
- 「表を挿入」で，表計算ソフトからコピーした，タブまたはカンマで区切ったセルを読み込めるようにした．行数と列数から「新しい表を作る」こともでき，見本のセルを編集して TeX または Markdown として挿入する．上限は 500 行，50 列，合計 10000 セルである．
- 最初の画面の「テンプレートから作成」または「編集の操作 → テンプレートを管理」で，日本語の文書，英語の文書，Beamer のスライド，Markdown のメモからプロジェクトを作れるようにした．自分の原稿からファイルを選んで登録し，名前と説明を変更することもできる．自分のテンプレートは最大 20 個，1 個につき最大 200 ファイル・合計 32 MiB である．生成した PDF，コンパイルの補助ファイル，編集履歴は含めない．

## 日本語: Markdown と外観

- Markdown の編集ツールバーから，見出し，太字，斜体，取消線，箇条書き，番号付きリスト，チェックリスト，引用，行内コード，リンク，コードブロック，表を挿入できるようにした．リンクやコードの画面で挿入する内容を確認でき，変更は Undo で取り消せる．
- Markdown の「スクロールを同期」を両方向にした．原稿を動かすとプレビュー，プレビューを動かすと原稿の表示が動く．初期状態はオンで，オフにして個別にスクロールすることもできる．
- 外観の初期値を「グレー」と「Consolas」にし，PC のライト／ダーク設定に合わせるようにした．保存済みの選択は引き続き使う．Consolas がない場合は，従来の「標準」と同じ順序で Cascadia Code，Menlo，DejaVu Sans Mono，ブラウザの等幅フォントを使う．「設定 → 外観」で変更できる．
- アウトラインから移動した場合や PDF をダブルクリックした場合に，原稿の該当行を上側に余白を設けて表示し，一時的に強調するようにした．

## 日本語: 更新する

Windows の ZIP 版は，原稿を保存して旧版を終了し，新しい ZIP を展開して `local-tex-web-editor.exe` を開く．既存の設定，草稿，選択した TeX Live は引き続き使える．

macOS では原稿を保存してアプリを終了し，「アプリケーション」の `.app` を新しいものに置き換えて開く．

Microsoft Store 版は，対応する更新の申請が公開されると更新できる．画面右下でアプリのバージョンを確認できる．詳しい操作と保存するデータの上限は [README](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/blob/main/README.ja.md)，前のバージョンの変更点は [v0.1.6](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/releases/tag/v0.1.6) にある．
