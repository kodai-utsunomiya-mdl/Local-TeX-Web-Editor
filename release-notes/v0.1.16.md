# Local TeX Web Editor 0.1.16

## TeX management

- Fixed an issue where **Remove the entire TeX environment…** could report that the folder had changed while the user was reviewing an unchanged installation. A background status refresh could create a temporary file to check write access while removal was reading the folder.
- Status refreshes now reuse confirmed environment information. The first check of an installation runs when other TeX management operations are idle. This also reduces repeated `kpsewhich` calls and temporary write checks during status updates.

## Development and release checks

Browser tests that intercept requests now explicitly block service workers, so the test can control when a copy response arrives. Browser restoration tests continue to use actual service workers and check reconnection after restarting the application.

## Updating

Save your documents and close the older application before opening the new version. The Microsoft Store update becomes available after its submission is published.

## 更新内容

### TeX の管理

- **「TeX の環境全体を削除…」** で，環境を変更していなくてもフォルダーが変更されたというエラーが表示される問題を修正した．状態の自動更新で書き込み可能かを確かめる一時ファイルが作られ，削除前の内容確認と同時に動くことが原因だった．
- 状態の更新には確認済みの環境情報を使い，初回の確認はほかの TeX 管理操作が動いていないときに行う．状態の更新に伴う `kpsewhich` の実行と一時ファイルによる書き込み検査の繰り返しも減らした．

### 開発時のテスト

要求を捕捉するブラウザテストでは Service Worker を明示的に無効にし，コピーの応答を返す時点をテストで制御できるようにした．ブラウザの復元テストでは実際の Service Worker を使い，アプリを起動し直した後の再接続を確認する．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．Microsoft Store 版は，対応する申請の公開後に更新できる．
