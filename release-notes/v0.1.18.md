# Local TeX Web Editor 0.1.18

## 日本語

- ホームと編集画面に **ZIP を読み込む…** を追加した．ZIP，保存先，新しいプロジェクト名を選ぶと，原稿を展開して開ける．
- **プロジェクトを ZIP でダウンロード** と **ZIP にして名前を付けて保存…** を追加した．編集中の原稿を保存してから，原稿，参考文献，画像，フォントなどを元のフォルダー構成でまとめる．
- ZIP の直下にプロジェクトのファイルを置き，Overleaf の **New Project → Upload Project** から読み込める形にした．
- アプリのキャッシュやコンパイルの中間ファイルを除き，図の PDF や参考文献の `.bbl`，外部の文書を参照する `.aux` などは含める．
- 初回起動からダークモードを使うようにした．外観の設定からライトやシステムに合わせるモードも選べる．

アプリの自動更新は初期状態で有効である．v0.1.17 からはアプリが更新を確認する．v0.1.16 以前の ZIP 版を使っている場合は，新しい版を一度導入すると，以降の自動更新を利用できる．Store 版は，Store の審査と公開の完了後に更新できる．

## English

- Added **Import ZIP…** to Home and the editor. Choose an archive, destination, and new project name to extract and open a project.
- Added **Download project as ZIP** and **Save project ZIP as…**. The app saves documents being edited and archives source, bibliography, images, fonts, and other project files with their relative folders.
- Place the project files at the ZIP root for import through Overleaf's **New Project → Upload Project**.
- Omit app caches and compilation intermediates while including PDF figures, `.bbl` bibliography files, and `.aux` files used to reference external documents.
- Start in Dark mode from the first launch. Light and System modes remain available in Appearance settings.

Automatic app updates remain enabled by default. Version 0.1.17 can check for this update. Install a current version once when upgrading from a ZIP edition of v0.1.16 or earlier. The Microsoft Store edition becomes available after Store review and publication.
