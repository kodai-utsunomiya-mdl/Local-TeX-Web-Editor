# Local TeX Editor 0.1.4

## Downloads

- **Windows:** `local-tex-editor-0.1.4-windows-x64.zip`
- **macOS:** `local-tex-editor-0.1.4-macos-universal.zip` for Apple Silicon and Intel, macOS 12 or later
- **Checksums:** `SHA256SUMS.txt`

Use your existing TeX Live installation. The app includes its own runtime; Python, Node.js and Go are not needed to run it.

## Changes

- Text selection is visible in both editor themes, including the active line, multiple lines and selections after focus moves elsewhere.
- Markdown files have a live preview with tables, code blocks, task lists, math and project images. Relative links open project files; double-clicking a paragraph jumps to its source line.
- Choose **Auto**, **PDF** or **Markdown** in the preview toolbar. Keep a PDF visible while writing Markdown, or keep Markdown visible while working on TeX. The choice is saved per project.
- **Compile** uses the active independent TeX document. Switching TeX tabs alone leaves the current PDF in place. Included chapters can use `% !TeX root = ../main.tex` or the default main document in Settings.
- Each document remembers its PDF page and zoom. A failed compilation leaves the preceding successful PDF and its SyncTeX data available.
- The initial UI language is **English**. Choose **Settings → Language → 日本語** for Japanese. The choice applies to future launches; document content and TeX output stay as written.
- **Settings → Add TeX packages** lists the available programs and prepares commands to add packages or find the package containing a missing file. Commands use your TeX folder and the matching repository for an older TeX Live release.
- A universal **macOS app** is included. Open it from Applications, Finder or Spotlight to launch the browser editor. Both Apple Silicon and Intel builds are tested with TeX Live and Chromium.
- Windows compilation handles Japanese names in the active document and project path.
- The README is available in English and Japanese, with prerequisites, smaller TeX installations, package additions and instructions for both operating systems.

## Updating

On **Windows**, extract the new ZIP and run its `.exe`. If an older app is running, follow the displayed instructions to save your work and close that version. The new editor then opens and existing installed shortcuts are updated.

On **Mac**, save your work and quit, replace the app in Applications with the new `.app`, and reopen it. First-launch guidance for the unsigned app is in the README.

Check that the lower-right corner shows **v0.1.4**. Your documents, settings, drafts and previous PDF remain available.

## 日本語: 変更した内容

- エディタで選択した文字の背景色を修正した．ライト／ダークの両方で，現在の行，複数行，エディタからフォーカスを移した後の範囲が見えるようになった．PDF の文字の選択色も確認した．
- `.md` と `.markdown` を編集している間は，右側に Markdown のプレビューを表示する．入力に合わせて更新し，表，コードブロック，チェック項目，プロジェクト内の画像，数式を表示する．「プレビュー」または `Ctrl + Enter` で保存して表示を更新できる．
- プレビュー上部で「自動・PDF・Markdown」を選べる．「PDF」では PDF を見ながら Markdown を編集できる．「Markdown」では TeX のタブへ移っても最後に編集した Markdown を表示する．「自動」では編集中のファイルに合わせて表示を切り替える．選んだ表示は，保存，コンパイル，次回の起動でも続けて使える．
- Markdown の相対リンクから別の文書を開ける．本文や見出しのダブルクリックでエディタの対応する行へ移動する．
- 独立した TeX 文書を開いてコンパイルすると，その文書の PDF を表示する．TeX のタブを切り替えただけでは，表示中の PDF は変わらない．
- 画面上部に次のコンパイル対象，PDF の操作欄に表示中の文書名を表示する．PDF の保存名と SyncTeX も，コンパイルした文書に対応する．
- 文書ごとに PDF のページ位置と倍率，中間ファイルを記録する．別の文書のコンパイルに失敗した場合も，直前に成功した PDF を参照できる．
- Markdown を表示している間に TeX のコンパイルが終わった場合も，PDF に戻ると記録したページ位置と倍率を使う．
- 初回の表示言語を English とし，設定から日本語を選べるようにした．選んだ言語は次回の起動でも使う．原稿，PDF，Markdown の本文と TeX の出力は元の内容で表示する．
- 設定に「TeX パッケージを追加」を加えた．利用可能なプログラムを確認し，パッケージ名や不足ファイル名から，追加・検索用のコマンドをコピーできる．旧年度の TeX Live では対応する取得先を指定する．
- Apple Silicon と Intel で使える macOS 版を追加した．`.app` を「アプリケーション」へ移し，Finder や Spotlight から開く．macOS 12 以降に対応する．
- Windows で日本語を含む原稿名をコンパイラーへ渡す処理を修正した．
- README を英語と日本語で用意し，必要なプログラム，小さめの TeX の構成，後からの追加，Windows / Mac の導入手順を記載した．

## コンパイルする文書

編集中の `.tex` に `\documentclass` または `\begin{document}` があれば，そのファイルをコンパイルする．`\input` で読む章や共通設定のファイルでは，設定画面の「既定のメイン文書」を使う．親ファイルを指定するには `% !TeX root = ../main.tex` と書く．パスは編集しているファイルのフォルダーから指定する．

プレビューが「自動」のときは，Markdown のタブから TeX のタブへ戻ると，最後にコンパイルした PDF を表示する．

## 日本語: 更新する手順

Windows:

1. `local-tex-editor-0.1.4-windows-x64.zip` をダウンロードして展開する．
2. 展開したフォルダーの `local-tex-editor.exe` を起動する．
3. 旧版が動いている場合は，表示された案内から原稿を保存して旧版を終了する．その後に新版の編集画面が開く．
4. 画面右下が `v0.1.4` になっていることを確認する．

設定，草稿，原稿，前回の PDF は引き続き使える．既存の TeX Live と SyncTeX を使い，追加のソフトウェアの導入は必要ない．作成済みの起動用ショートカットも，新版の起動時に更新される．

Mac では，原稿を保存してアプリを終了し，`local-tex-editor-0.1.4-macos-universal.zip` にある `Local TeX Editor.app` で「アプリケーション」の旧版を置き換える．初回の起動方法は README にある．
