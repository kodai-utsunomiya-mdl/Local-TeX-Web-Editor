# Local TeX Editor 0.1.4

## 変更した内容

- エディタで選択した文字の背景色を修正した．ライト／ダークの両方で，現在の行，複数行，エディタからフォーカスを移した後の範囲が見えるようになった．PDF の文字の選択色も確認した．
- `.md` と `.markdown` を編集している間は，右側に Markdown のプレビューを表示する．入力に合わせて更新し，表，コードブロック，チェック項目，プロジェクト内の画像，数式を表示する．「プレビュー」または `Ctrl + Enter` で保存して表示を更新できる．
- プレビュー上部で「自動・PDF・Markdown」を選べる．「PDF」では PDF を見ながら Markdown を編集できる．「Markdown」では TeX のタブへ移っても最後に編集した Markdown を表示する．「自動」では編集中のファイルに合わせて表示を切り替える．選んだ表示は，保存，コンパイル，次回の起動でも続けて使える．
- Markdown の相対リンクから別の文書を開ける．本文や見出しのダブルクリックでエディタの対応する行へ移動する．
- 独立した TeX 文書を開いてコンパイルすると，その文書の PDF を表示する．TeX のタブを切り替えただけでは，表示中の PDF は変わらない．
- 画面上部に次のコンパイル対象，PDF の操作欄に表示中の文書名を表示する．PDF の保存名と SyncTeX も，コンパイルした文書に対応する．
- 文書ごとに PDF のページ位置と倍率，中間ファイルを記録する．別の文書のコンパイルに失敗した場合も，直前に成功した PDF を参照できる．
- Markdown を表示している間に TeX のコンパイルが終わった場合も，PDF に戻ると記録したページ位置と倍率を使う．

## コンパイルする文書

編集中の `.tex` に `\documentclass` または `\begin{document}` があれば，そのファイルをコンパイルする．`\input` で読む章や共通設定のファイルでは，設定画面の「既定のメイン文書」を使う．親ファイルを指定するには `% !TeX root = ../main.tex` と書く．パスは編集しているファイルのフォルダーから指定する．

プレビューが「自動」のときは，Markdown のタブから TeX のタブへ戻ると，最後にコンパイルした PDF を表示する．

## 更新する手順

1. `local-tex-editor-0.1.4-windows-x64.zip` をダウンロードして展開する．
2. 展開したフォルダーの `local-tex-editor.exe` を起動する．
3. 旧版が動いている場合は，表示された案内から原稿を保存して旧版を終了する．その後に新版の編集画面が開く．
4. 画面右下が `v0.1.4` になっていることを確認する．

設定，草稿，原稿，前回の PDF は引き続き使える．既存の TeX Live と SyncTeX を使い，追加のソフトウェアの導入は必要ない．作成済みの起動用ショートカットも，新版の起動時に更新される．
