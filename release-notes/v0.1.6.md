# Local TeX Web Editor 0.1.6

## Changes

- Resize the files and outline sidebar by dragging its right edge, and resize the compilation log by dragging its top edge. The app saves these sizes and the editor/preview split for the next launch.
- Use the arrow keys on a focused divider to adjust its position. Double-click it or press Enter to return that divider to its initial position.
- Fixed PDF text drifting sideways during repeated zoom changes. The **＋** / **−** buttons and zoom selector use the PDF position at the center of the preview. Ctrl+wheel and pinch zoom around the pointer or gesture position.
- The outline follows the selected TeX or Markdown tab. Click a heading to move to its source line.
- Jump from Markdown source to the matching preview location with Ctrl+click on Windows or Cmd+click on macOS, or use the navigation button above the editor. The matching block is highlighted briefly.
- Let the Markdown preview follow the editor as you scroll. The **Sync scrolling** checkbox above the preview turns this on or off, and the app saves your choice. Scrolling sync starts enabled.
- Enlarged the close buttons and spacing in the source search/replace panel and PDF search bar.

## Updating

For the Windows ZIP edition, extract the new ZIP and open `local-tex-web-editor.exe`. Save your documents and close the earlier version if it is running. Your settings, drafts and configured TeX Live installation remain available.

On macOS, save your documents and quit, replace the app in Applications with the new `.app`, and reopen it.

Microsoft Store updates become available after the corresponding Store submission is published. Check the version at the lower right of the editor.

## 日本語: 変更した内容

- ファイル一覧・アウトラインの右端と，コンパイルログの上端をドラッグして，幅や高さを変更できるようにした．原稿とプレビューの幅を含め，選んだ大きさを次回の起動時にも使う．
- 境界にフォーカスして矢印キーを押すと，位置を調整できる．ダブルクリックまたは Enter で，操作した境界を初期位置に戻せる．
- PDF の拡大・縮小を繰り返すと，本文が横へずれていく動きを修正した．`＋` / `−` と倍率の選択はプレビュー中央の PDF 上の位置，`Ctrl + ホイール` とピンチはポインターやジェスチャーの位置を基準に拡大・縮小する．
- アウトラインを，選択中の TeX または Markdown のタブに合わせて切り替えるようにした．見出しをクリックすると，原稿の行へ移動できる．
- Markdown の原稿で Windows では Ctrl+クリック，macOS では Cmd+クリックすると，対応するプレビューの位置へ移動できるようにした．原稿の上にある移動ボタンでも操作でき，移動先を短時間ハイライトする．
- 原稿のスクロールに Markdown のプレビューが追従するようにした．プレビューの上にある「スクロールを同期」で切り替え，選択した設定を保存する．初期状態はオンになっている．
- 原稿の検索・置換欄と PDF の検索欄で，閉じるボタンを大きくし，周囲の余白を広げた．

## 日本語: 更新する

Windows の ZIP 版は，新しい ZIP を展開して `local-tex-web-editor.exe` を開く．旧版が動いている場合は，原稿を保存して終了する．設定，草稿，選択した TeX Live は引き続き使える．

macOS では原稿を保存してアプリを終了し，「アプリケーション」の `.app` を新しいものに置き換えて開く．

Microsoft Store 版は，対応する更新の申請が公開されると更新できる．画面右下でアプリのバージョンを確認できる．
