# Local TeX Web Editor 0.1.22

## 日本語

- 通常は原稿を開き，「コンパイル」を押すだけで組版できます．原稿のフォルダーからプロジェクトのルートまで順に探して最も近い `latexmkrc` または `.latexmkrc` を使い，見つからなければ pdfLaTeX を使います．
- ZIP を開いた場合も同じ動作です．付属の日本語テンプレートには LuaLaTeX の設定ファイルが入ります．
- 旧版の標準値を保存していたプロジェクトは，次に開くと新しい標準に切り替わります．旧版では手動で同じ値を選んだ場合も同じ形式で保存していたため，これも初回の切り替えに含まれます．更新後に選んだ設定は次回も引き継がれます．
- ツールバーで「ファイル内」と「プロジェクト全体」の間隔を少し広げました．

[日本語の README](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/blob/main/README.ja.md) · [図付きの操作ガイド](https://kodai-utsunomiya-mdl.github.io/Local-TeX-Web-Editor/ja/)

## English

- Open a manuscript and click **Compile**. By default the editor searches from the manuscript’s folder up to the project root for the nearest `latexmkrc` or `.latexmkrc` and uses pdfLaTeX when it finds neither.
- ZIP imports follow the same rule. The built-in Japanese template includes a configuration for LuaLaTeX.
- Older projects with a saved compiler matching the previous default switch once when reopened. This includes manual selections of the same value, which older versions stored identically. Compiler choices made after updating are remembered.
- The two search and replace buttons are spaced slightly farther apart.
