# Local TeX Web Editor 0.1.8

## Resume work after leaving the browser tab

The local app now continues running when an editor tab sleeps, is discarded, or closes. A returning page reconnects to the same local address and refreshes its connection. Drafts and tab positions are recorded as the page becomes inactive. Use **Quit** at the top right to stop the app and any running compilation; launching the same version again opens the running editor.

This replaces the previous behavior that stopped the app about five seconds after the last browser connection ended.

## Manage project files and edit code

Right-click a file or folder to create a file or folder there, copy a relative or full path, rename it, or delete it. `Shift + F10` or the context-menu key opens the same menu; `F2` opens Rename, and `Delete` asks for confirmation. Folder deletion is available for empty folders.

Renaming updates open tabs and their editing state, including unsaved text. References already written in documents can be updated with the existing search and replace tools.

Program and configuration files use the editor's saving, search, drafts, and history. Syntax highlighting supports Python, JavaScript/TypeScript, C/C++, Java, Kotlin, C#, Go, Rust, R, Ruby, shell, PowerShell, HTML, CSS, XML, SQL, JSON, YAML, TOML, and Lua. Other supported formats open as plain text; `.ipynb` opens as JSON text.

## Create Markdown pages and convert documents

The **Editing tools** menu has three new actions:

- **New Markdown page** creates a file with a title heading, inserts a relative link into the current document, and optionally opens the new page. Existing files are not overwritten. Undo removes the inserted link; the created file stays in the project.
- **Save Markdown as PDF** previews the current text, including unsaved edits, mathematics, tables, and project images. **Print / Save as PDF** opens the browser's print dialog. Select its PDF destination and choose the page size and margins there. TeX Live is not needed for this operation.
- **Convert PDF to text** extracts text from the displayed compiled PDF or a project PDF in page order. Review the preview, then download UTF-8 TXT. It shows progress and can be cancelled. Output is limited to 16 MiB. Scanned images need OCR; complex columns, equations, or font mappings can affect extracted text.

These features use the existing Markdown renderer, browser printing, and PDF.js. No dependency packages were added.

## Interface changes

- **Close all tabs** offers Save, Discard, or Cancel for unsaved text. Closing all tabs also leaves the next session with no open tabs.
- The tab strip scrolls horizontally with the mouse wheel, trackpad, or touch, without a vertical scrollbar.
- **Settings → 言語設定 / Language** always shows the bilingual label. Choosing a language updates the interface immediately. Save applies it to later sessions; Cancel or `Esc` restores the saved choice.
- PDF **＋**, **−**, **Save PDF**, and the page-number field stay visible in narrow previews. Other controls move into **… (PDF actions)** as space decreases, and the toolbar stays on one row.
- The completion explanation and automatic-suggestion option have more space between them.

## Update

Save your documents and quit the old app before opening the new version. For the Windows ZIP edition, extract the new ZIP and open `local-tex-web-editor.exe`. On macOS, replace the app in Applications. Settings, drafts, and the TeX Live location carry over.

Microsoft Store updates become available after the corresponding submission is published. See the version at the lower right of the editor and [the user guide](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/blob/main/README.md).

## 日本語

### 別のタブで作業した後も再開する

編集タブが休止したり閉じられたりしても，アプリは動作を続ける．タブへ戻ると同じローカルアドレスへ接続し直す．ページから離れるときに草稿とタブの位置を記録する．アプリとコンパイル中の処理を止めるときは，右上の終了ボタンを使う．同じ版をもう一度起動した場合は，起動中の編集画面を開く．

従来は最後のブラウザ接続が終了すると約 5 秒後にアプリも終了していた．今回，この終了処理を変更した．

### ファイル操作とプログラムの編集

ファイルやフォルダーの右クリックから，新規ファイル・フォルダーの作成，相対パス・絶対パスのコピー，名前の変更，削除を選べる．`Shift + F10` またはメニューキーでも同じメニューを開ける．`F2` は名前の変更，`Delete` は削除の確認へ進む．フォルダーは空の場合に削除できる．

名前を変えると，開いているタブと編集中の本文も新しいパスへ移る．別の原稿に書いたリンクや参照先は，検索・置換などで変更できる．

Python，JavaScript/TypeScript，C/C++，Java，Kotlin，C#，Go，Rust，R，Ruby，shell，PowerShell，HTML，CSS，XML，SQL，JSON，YAML，TOML，Lua などを色付けして編集できる．そのほかの対応形式はプレーンテキストとして開き，`.ipynb` は JSON のテキストとして扱う．保存，検索，草稿，履歴も使える．

### Markdown のページ作成と文書の変換

「編集の操作」に次の操作を追加した．

- **新しい Markdown ページ**: タイトルの見出しを持つファイルを作成し，現在の文書へ相対リンクを挿入する．作成後に新しいページを開くか選べる．元の文書で Undo を使うと挿入したリンクが戻り，作成したファイルはプロジェクトに残る．
- **Markdown を PDF に保存**: 未保存の本文，数式，表，プロジェクト内の画像を含む印刷プレビューを開く．「印刷画面で PDF に保存」からブラウザの PDF 保存先，ページサイズ，余白を選ぶ．TeX Live がなくても使える．
- **PDF をテキストに変換**: 表示中のコンパイル結果またはプロジェクト内の PDF から文字をページ順に取り出し，UTF-8 の TXT を保存する．進捗とキャンセルに対応し，出力の上限は 16 MiB である．スキャンした画像の文字には OCR が必要である．段組，数式，フォントの情報によっては，文字の順序や表記に差が出る．

既存の Markdown の描画，ブラウザの印刷，PDF.js を使い，依存パッケージの追加はない．

### 画面の操作

- **すべてのタブを閉じる**: 未保存の本文について保存・破棄・キャンセルを選べる．すべて閉じた場合は，次回も空のタブ欄で再開する．
- タブ欄を上下にスクロールさせず，ホイール・トラックパッド・タッチで横へ移動できるようにした．
- **言語設定 / Language** を常に日英で併記し，選択直後に画面の言語を切り替える．保存で次回に反映し，キャンセルまたは `Esc` で元へ戻す．
- 狭い PDF 表示欄でも **＋・−・PDF の保存・ページ番号** は常に表示する．ほかの操作は幅に応じて「… (PDF の操作)」へ移し，1 行の配置を続ける．
- TeX の補完の説明と，入力中に候補を自動表示する項目との余白を広げた．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．Windows の ZIP 版は新しい ZIP を展開し，`local-tex-web-editor.exe` を起動する．macOS 版は「アプリケーション」のアプリを置き換える．設定，草稿，TeX Live の場所は引き続き使える．

Microsoft Store 版は，対応する申請の公開後に更新できる．画面右下で版を確認でき，[README](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/blob/main/README.ja.md) に操作手順がある．
