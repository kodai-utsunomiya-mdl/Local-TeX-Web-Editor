# Local TeX Web Editor 0.1.13

## Easier TeX setup and package management

- Home and Settings show **Set up TeX…** and **Manage TeX…** together. You can install a new environment even when an existing TeX installation is already selected.
- TeX management has more space between explanations and actions, with buttons that wrap on smaller screens.
- Package presets, package names and **Add SyncTeX…** lead to the app's installation review. Shared installations that need an external manager open their official TeX management tool.
- Setup creates the default destination when the folder shown in the review has not been created yet.
- The setup guide follows the actual app screens from Home through package and destination review, progress, completion and compilation.

## Reset saved settings and information

- Open **Settings → Reset settings and remembered information…** to review the app's data location, file counts and sizes.
- Reset settings, recent projects, tabs, editing positions and the selected TeX path. Unsaved drafts, document history, custom templates and PDF/SyncTeX caches are separate choices, initially unchecked.
- Project files and installed TeX remain available. If the current document has unsaved changes, save them first or choose the draft/discard action shown for the selected reset items.
- After the reset, the app reloads. Another open tab offers downloads of its unsaved documents before reloading, and its older settings cannot overwrite the new state.

## 更新内容

### TeX の導入と追加を進めやすくする

- ホームと設定に「TeX をセットアップ…」と「TeX を管理…」を並べた．既存の TeX を選んでいる場合も，新しい環境の導入へ進める．
- 管理画面の説明とボタン，ボタン同士の余白を広げ，狭い画面では折り返すようにした．
- パッケージの候補，名前の入力，「SyncTeX を追加…」から，アプリ内の追加内容の確認へ進める．公式の管理ツールが必要な共用環境では，そのツールを開く．
- 確認画面に表示された既定の保存先が未作成の場合も，導入時にフォルダーを作成する．
- 導入ガイドは，ホーム，追加する内容と保存先，進捗，完了，コンパイルを実際のアプリの画面に沿って説明する．

### 設定と記憶した情報を初期化する

- 「設定 → 設定と記憶した情報を初期化…」に，アプリの保存先，ファイル数，容量を表示する．
- 設定，最近開いたプロジェクト，タブ，編集位置，選択した TeX の場所を初期化できる．未保存の草稿，編集履歴，自作テンプレート，PDF / SyncTeX のキャッシュは個別に選択し，最初はオフにしている．
- プロジェクトの原稿と導入済みの TeX は引き続き使える．未保存の原稿があるときは，ファイルへ保存するか，選んだ初期化の内容に応じて草稿へ残す・破棄する操作へ進む．
- 初期化後はアプリを開き直す．別のタブには，未保存の原稿をダウンロードする画面を表示する．古いタブからの書き込みで初期化前の設定が戻ることも防ぐ．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．Microsoft Store 版は，対応する申請の公開後に更新できる．
