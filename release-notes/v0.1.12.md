# Local TeX Web Editor 0.1.12

## Install TeX from the app

- Home, Settings and a compile attempt with missing tools offer TeX setup. Review the source, destination, package list and disk-space estimate before starting.
- Setup downloads the fixed TinyTeX v2026.11 release, verifies its SHA-256 value, and adds the programs and packages for Japanese research documents. Progress, logs, cancellation and retry are available in the app.
- The initial configuration supports upLaTeX with dvipdfmx, pdfLaTeX, XeLaTeX, LuaLaTeX, bibliography processing and SyncTeX. It includes Harano Aji and Latin Modern fonts, mathematics, distinct theorem references, TikZ, tcolorbox, tables and algorithms.
- The selected environment becomes available without restarting the app. Markdown editing remains available during installation.

## Manage packages in the selected TeX environment

- Open **Settings → Manage TeX…** to search installed packages, add packages by their TeX Live names, download a package again, or remove selected packages after reviewing the complete list of affected packages.
- Existing TeX Live, MacTeX and TinyTeX installations use their own package manager. The app checks the actual installation folder and applies the change to the selected environment.
- The ZIP and macOS editions use OS authorization when the selected environment requires administrator access. The Store edition can directly manage user-writable environments; for a protected system environment, it can open the installed official TeX Live GUI.
- Package removal rechecks the package database and the displayed plan before running. Dependencies required by other installed packages are checked by TeX Live.

## Review an environment before removing it

- Review the actual installation folder, file count and size, then enter its folder name before starting removal inside the app.
- An environment installed by this app is checked against its recorded file list. Additional files stop removal so that you can inspect them.
- Existing environments use the Windows uninstaller supplied with TeX Live or the operating system's Trash operation. Unregistered manuscripts, documents or images are shown for review before this operation. The Store edition opens Windows app settings for a shared or protected installation; confirm its removal there and refresh the environment in the editor.
- Other editors using the same TeX environment will need another installation after removal. Keep manuscripts and personal files in their own project folders.

## Update

Save your documents and quit the old app before opening the new version. Settings, drafts and the selected TeX folder carry over. Microsoft Store updates become available after the corresponding submission is published.

## 日本語

### アプリから TeX を導入する

- ホーム，設定，必要なプログラムがない状態でのコンパイルから，TeX の導入へ進める．配布元，保存先，パッケージ，容量の目安を確認して開始する．
- 固定した TinyTeX v2026.11 を取得し，SHA-256 の値を確認して，日本語の研究用原稿で使うプログラムとパッケージを追加する．進捗，ログ，停止，再試行をアプリ内で操作できる．
- 初期構成は upLaTeX と dvipdfmx，pdfLaTeX，XeLaTeX，LuaLaTeX，文献処理，SyncTeX に対応する．原ノ味フォント，Latin Modern，数式，定理の種類ごとの相互参照，TikZ，tcolorbox，表，アルゴリズムのパッケージを含む．
- 導入後はアプリを再起動せずに使用できる．導入中も Markdown を編集できる．

### 選択中の TeX のパッケージを管理する

- 「設定 → TeX を管理…」で，導入済みのパッケージを検索し，TeX Live のパッケージ名を指定して追加・再取得できる．削除するときは，関連する対象を含む一覧を確認して進める．
- 既存の TeX Live，MacTeX，TinyTeX では，その環境の管理ツールを使う．実際の保存先を確認し，選択中の環境へ変更を適用する．
- ZIP 版と macOS 版では，必要に応じて OS が管理者の承認を求める．Store 版はユーザーの権限で書き込める環境を直接管理でき，管理者用の環境では，付属の公式 TeX Live GUI を開ける．
- パッケージの削除前に，パッケージの記録と確認画面の内容を再確認する．他のパッケージが必要とする依存関係は TeX Live が確認する．

### 環境全体の削除前に内容を確認する

- 実際の保存先，ファイルの件数，容量を確認し，アプリ内で削除を開始する場合はフォルダー名を入力して進める．
- アプリが導入した環境は，導入時のファイル一覧と照合する．追加のファイルが見つかった場合は削除を止め，内容を確認できる．
- 既存の環境では，TeX Live に付属する Windows のアンインストーラーや，OS のごみ箱の操作を使う．未登録の原稿，文書，画像がある場合は，その内容を先に確認できる．Store 版で共用または管理者用の環境を使う場合は，Windows のアプリ設定を開く．そこで対象を確認して削除し，エディタの環境の表示を更新する．
- 同じ TeX を使っている他のエディタも，削除後は次の環境を選ぶ必要がある．原稿や自分のファイルは，各プロジェクトのフォルダーへ保存する．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．設定，草稿，選択中の TeX の場所は引き続き使える．Microsoft Store 版は，対応する申請の公開後に更新できる．
