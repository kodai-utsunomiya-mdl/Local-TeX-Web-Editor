# Local TeX Web Editor 0.1.17

## 日本語

- アプリの自動更新を初期状態で有効にした．起動後に更新を確認し，バックグラウンドで取得する．
- 編集画面へ更新の進捗を表示し，設定へ **今すぐ確認** と自動更新の設定を追加した．通知の **1 時間後に更新** で適用を延期できる．
- 開いている全ての編集画面で未保存の原稿，コンパイル，TeX の操作，最近の入力を確認し，草稿と編集位置を書き出してから更新する．再起動後は同じブラウザタブで編集を再開する．
- Windows の ZIP 版に，署名付き更新情報の検証，更新ファイルの入れ替え，起動失敗時に元の版へ戻す処理を追加した．
- Store 版では Microsoft Store の更新 API，macOS 版では Sparkle を使って確認・取得・適用を進める．

v0.1.16 以前の ZIP 版を使っている場合は，この版を一度導入すると，以降はアプリの自動更新を利用できる．Store 版は，Store の審査と公開の完了後に更新できる．

## English

- Enabled automatic application updates by default. The app checks after startup and downloads updates in the background.
- Added update progress, **Check now**, an automatic update setting, and **Update in one hour**.
- Updates wait for every open editor to finish saving and for compilation, TeX operations, and recent input to settle. Drafts and editor positions are written before restarting, and the same browser tabs reconnect afterward.
- Added signed update verification, executable replacement, and recovery of the previous executable if a new Windows ZIP version fails to start.
- Added native Microsoft Store updates and Sparkle updates for macOS.

Install this version once when upgrading from a ZIP edition of v0.1.16 or earlier. Subsequent updates can run automatically. The Microsoft Store edition becomes available after Store review and publication.
