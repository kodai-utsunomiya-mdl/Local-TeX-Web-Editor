# Local TeX Web Editor 0.1.9

## Interface labels and Markdown tools

- The formatting toolbar above Markdown source includes labelled **Image**, **Table**, and **New page** buttons. They open the existing insertion and linked-page dialogs, and wrap onto another row in narrow panes.

- The language setting always reads **Language / 言語設定**, with English first. Selecting a language still updates the interface immediately; Save applies it to future sessions, and Cancel or `Esc` restores the saved language.
- The file-list context menu now reads **Delete**. Choosing it still opens the confirmation dialog before deleting a file or an empty folder.

## Closing the application

Use **Quit** at the top right to end the application. The app continues running while a browser tab sleeps or is discarded, so returning to the tab can reconnect. Closing a browser tab or window also leaves the app running. This behavior is the same as in version 0.1.8.

## Update

Save your documents and quit the old app before opening the new version. Settings, drafts, and the TeX Live location carry over. Microsoft Store updates become available after the corresponding submission is published.

## 日本語

### 画面の表記と Markdown の操作

- Markdown の原稿の上にある書式ツールバーに，文字付きの **画像・表・新規ページ** ボタンを配置した．画像や表の挿入と，リンク付きのページ作成を直接開ける．表示幅が狭い場合は次の行へ折り返す．

- 言語設定の項目名を **Language / 言語設定** とし，日本語と英語のどちらの画面でも英語を先に表示するようにした．言語を選ぶとその場で表示が切り替わり，保存で次回に反映し，キャンセルまたは `Esc` で元へ戻る．
- ファイル一覧の右クリックメニューを **削除** に揃えた．選択後には確認画面が開き，ファイルまたは空のフォルダーを削除するか選べる．

### アプリを終了する

アプリを終了するときは右上の終了ボタンを使う．ブラウザのタブが休止したり破棄されたりしても，アプリは動作を続け，タブへ戻ったときに再接続できる．タブやブラウザのウィンドウを閉じた場合も動作を続ける．この動作は v0.1.8 と共通である．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．設定，草稿，TeX Live の場所は引き続き使える．Microsoft Store 版は，対応する申請の公開後に更新できる．
