# Local TeX Web Editor 0.1.9

## Edit Markdown directly

- Markdown opens in **Visual editing**. Edit rendered headings, paragraphs, lists, table cells, and code, tick task checkboxes, and select equations to edit their TeX.
- Switch to **Source** to edit the Markdown notation. The two modes share saving, autosave, drafts, and undo. Changing the display mode leaves the text unchanged; editing a block visually keeps the original Markdown of the other blocks.
- Each editor pane remembers its editing mode, including when the same document is open in two panes.

## Show or hide the preview

- **Show preview / Hide preview** opens or closes the preview and restores its previous width when reopened.
- The preview starts closed for visual Markdown editing, and open for Markdown source and TeX. Manual changes are remembered for each mode.
- Fixed empty space at the right edge after moving the divider to a limit or resizing the window. Both columns now use the available width when either column reaches its minimum.

## PDF navigation and citations

- **Back** and **Forward** remain visible beside the page number, zoom buttons, and download button at every preview width.
- **… (PDF actions)** shows the PDF file name, the full project path of the compiled TeX document, and the PDF's update status. It is available in wide and narrow previews.
- Hover over a PDF citation link or focus it with `Tab` to read the title, author, and year from the project's bibliography. Hyperref, natbib, and biblatex citation links work in the compiled preview and project PDF tabs. `Esc` closes the tooltip.

## Appearance

- Choose from seven color schemes, eight accent colors, and ten editor fonts. Gray and Consolas appear first and are marked as the defaults. The former Default color scheme is named Blue gray; the former Default font is named Cascadia Code.
- Set background, text, and accent colors with a color picker or a hexadecimal code. Light and dark modes save their colors independently. Clear a code, or use **Use the color scheme for this mode**, to return to the selected scheme.
- The selected colors apply to popups, notifications, compilation results, drafts, and connection status. Buttons use a readable text color for light and dark accents.

## Manage projects and add files

- The **TeX logo** opens Home, where project cards show the current and recent folders with their full paths. Return to editing resumes the same workspace and unsaved text.
- Delete a project from Home after reviewing its contents and drafts, checking the acknowledgment, and entering its exact name. The app requests another review if the files or drafts change before deletion.
- Delete nonempty folders from the file-list context menu after reviewing their contents and unsaved documents.
- **Add files from your computer…** opens the file picker from the file-list toolbar or context menu. Copy multiple files to a chosen project folder, and choose replacement, a different name, or skipping when a name already exists. The new-file dialog still accepts a project-relative path.

## Select and manage edit history

- Select multiple recorded versions with checkboxes, select all, or use `Shift`-click to select a range. **Delete … selected versions…** lists their names and dates before confirmation.
- Select multiple changes from an earlier version and restore them together. Each list shows its selection count and has its own select-all control. Restored text can be undone in the editor.
- Empty edit history uses the available width and wraps its explanation at sentence and clause boundaries.

## Interface labels and Markdown tools

- The formatting toolbar above Markdown source includes labelled **Image**, **Table**, and **New page** buttons. They open the existing insertion and linked-page dialogs, and wrap onto another row in narrow panes.

- The language setting always reads **Language / 言語設定**, with English first. Selecting a language still updates the interface immediately; Save applies it to future sessions, and Cancel or `Esc` restores the saved language.
- **Delete…** opens a confirmation screen; the button inside that screen performs the deletion.
- Cancelling a file operation immediately restores keyboard navigation, so another file's context menu can be opened without waiting for a later dialog event.

## Closing the application

Use **Quit** at the top right to end the application. The app continues running while a browser tab sleeps or is discarded, so returning to the tab can reconnect. Closing a browser tab or window also leaves the app running. This behavior is the same as in version 0.1.8.

## Update

Save your documents and quit the old app before opening the new version. Settings, drafts, and the TeX Live location carry over. Microsoft Store updates become available after the corresponding submission is published.

## 日本語

### Markdown を直接編集する

- Markdown は初期状態で「直接編集」を使う．表示された見出し，本文，リスト，表のセル，コードを編集し，タスクのチェックや数式の TeX をその場で変更できる．
- 「ソース」に切り替えると Markdown の記法を編集できる．保存，自動保存，草稿，Undo は両方の表示で共通の文書へ反映する．表示を切り替えた時点では本文はそのままで，直接編集では変更したブロックに対応する原稿を書き換える．
- 二つのエディタでは各ペインの表示方法を覚える．同じ文書を二つの表示で編集できる．

### プレビューを表示する・閉じる

- 「プレビューを表示 / プレビューを閉じる」で表示を切り替えられる．再表示すると元の幅へ戻る．
- 直接編集ではプレビューを閉じ，Markdown のソース編集と TeX では表示することを初期値とする．手動で変えた状態はモードごとに次回へ反映する．
- 境界を端まで動かした後やウィンドウの幅を変えた後に，右端へ大きな空きが生じる問題を修正した．片方が最小幅に達した場合にも，両方の列で利用できる幅を使う．

### PDF の移動と文献の確認

- プレビューの幅に応じて操作欄を整え，「戻る」「進む」，ページ番号，拡大・縮小，保存のボタンを常に表示する．
- 「… (PDF の操作)」に，PDF のファイル名，コンパイルした TeX のプロジェクト内のパス，PDF の更新状態を表示する．広い画面と狭い画面の両方で確認できる．
- PDF の引用リンクにカーソルを合わせるか `Tab` でフォーカスすると，プロジェクトの文献情報からタイトル・著者・年を表示する．hyperref，natbib，biblatex の引用リンクに対応し，コンパイルした PDF とファイル一覧から開いた PDF で使える．`Esc` で文献の表示を閉じる．

### 外観

- 配色を 7 種，アクセントを 8 色，フォントを 10 種から選べるようにした．グレーと Consolas を先頭に置き，初期値と表示する．従来の配色の「標準」は「ブルーグレー」，フォントの「標準」は「Cascadia Code」と表記する．
- 背景・文字・アクセントを色の選択欄やカラーコードで指定できる．ライトとダークの色はそれぞれ保存する．コードを空にするか「このモードの色を配色に戻す」を押すと，選んだ配色の色へ戻る．
- ポップアップ，通知，コンパイル結果，草稿，接続状態にも選んだ色を反映する．明るいアクセントでもボタンの文字を読める配色にする．

### プロジェクトを管理し，ファイルを追加する

- **TeX のロゴ**からホームを開き，現在と最近使ったプロジェクトを絶対パス付きのカードで管理できる．「編集に戻る」では，同じ編集画面と未保存の本文から作業を続けられる．
- ホームからプロジェクトを削除できる．中身と草稿を確認し，チェックとプロジェクト名の入力を済ませて実行する．確認後にファイルや草稿が変わった場合は，再び確認画面を表示する．
- ファイル一覧の右クリックから，中身のあるフォルダーを削除できる．確認画面で中身と未保存の原稿を確認する．
- ファイル一覧のボタンや右クリックの「コンピューターからファイルを追加…」で，選択画面から複数のファイルを選び，プロジェクトのフォルダーへコピーできる．同名のファイルがあるときは，置き換える，別名で追加，スキップから選ぶ．新規ファイルの画面でプロジェクト内のパスを入力する方法も使える．

### 編集履歴を選択して整理する

- 記録した版をチェックボックスで複数選び，「選択した … 版を削除…」から名前と日時を確認して削除できる．すべての版の選択と，`Shift` を押しながらのクリックによる範囲の選択にも対応する．
- 以前の版から戻したい変更箇所も複数選び，まとめて原稿へ反映できる．版と変更箇所にはそれぞれ選択数と一括選択の操作があり，復元した内容はエディタの Undo で取り消せる．
- 編集履歴が空の場合は説明を表示領域の幅で示し，文や節の区切りで改行するようにした．

### 画面の表記と Markdown の操作

- Markdown の原稿の上にある書式ツールバーに，文字付きの **画像・表・新規ページ** ボタンを配置した．画像や表の挿入と，リンク付きのページ作成を直接開ける．表示幅が狭い場合は次の行へ折り返す．

- 言語設定の項目名を **Language / 言語設定** とし，日本語と英語のどちらの画面でも英語を先に表示するようにした．言語を選ぶとその場で表示が切り替わり，保存で次回に反映し，キャンセルまたは `Esc` で元へ戻る．
- 「削除…」から確認画面を開き，画面内の実行ボタンで削除する．
- ファイル操作の確認をキャンセルすると，直ちにキーボードで次のファイルやメニューを操作できるようにした．

### アプリを終了する

アプリを終了するときは右上の終了ボタンを使う．ブラウザのタブが休止したり破棄されたりしても，アプリは動作を続け，タブへ戻ったときに再接続できる．タブやブラウザのウィンドウを閉じた場合も動作を続ける．この動作は v0.1.8 と共通である．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．設定，草稿，TeX Live の場所は引き続き使える．Microsoft Store 版は，対応する申請の公開後に更新できる．
