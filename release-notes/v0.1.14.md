# Local TeX Web Editor 0.1.14

## TeX setup and illustrated guides

- TeX setup leaves more space between the current-environment box and the progress or completion message.
- The website, README and Store listing use a screenshot of direct Markdown editing, with rendered headings, equations, task checkboxes and a table.
- The website and README guide users through downloading the app, opening it and compiling their first document. They explain both installing TeX from the app on a computer without TeX and selecting an existing installation.
- Japanese website text has clearer spacing around controls and links. The reset choices use consistent emphasis.
- The website explains the SmartScreen steps directly: open **More info**, check the app name, then choose **Run anyway**. Release notes remain available through the existing links.

## 更新内容

- TeX のセットアップで，現在の環境を示す枠と，進行中・完了時のメッセージの間に余白を設けた．
- サイト，README，Store の掲載用画像を，Markdown の本文を直接編集する画面へ更新した．見出し，数式，チェック項目，表を表示している．
- サイトと README を，アプリの入手と起動から最初のコンパイルへ進める構成へ改めた．TeX がない PC ではアプリから導入し，既にある場合はその環境を選ぶ手順を説明する．
- 日本語サイトで操作名やリンクと前後の文章の間隔を整え，初期化する項目の強調をそろえた．
- SmartScreen の「Windows によって PC が保護されました」が出た場合は，「詳細情報」でアプリ名を確認し，「実行」を選ぶ手順をサイトに追記した．更新内容は既存の Release notes へのリンクから読める．
