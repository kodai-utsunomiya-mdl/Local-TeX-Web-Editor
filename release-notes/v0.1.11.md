# Local TeX Web Editor 0.1.11

## Resize text in Markdown visual editing

- In **Visual editing**, use `Ctrl + wheel`, a trackpad pinch, or a two-finger pinch on a touchscreen to change the text size. `Cmd + wheel` also works on Mac.
- Visual editing and source editors share the 8–40 px size shown in Settings. Both editor panes update, and the chosen size is saved for the next session.

## Delete compiled PDF results

- Right-click an entry under **Compiled PDFs** and choose **Delete…**. Review the TeX document and the number of files, then choose **Delete**.
- Deletion removes that TeX document's cached PDF and SyncTeX results, including earlier versions, and its compilation output and auxiliary files. The source document and PDFs saved or copied as ordinary files stay in place.
- If the displayed result is deleted, the preview opens the most recent remaining PDF or becomes empty when none remain. Compiling the TeX document again creates a new PDF and adds it to the list.

## Update

Save your documents and quit the old app before opening the new version. Settings, drafts, and the TeX Live location carry over. Microsoft Store updates become available after the corresponding submission is published.

## 日本語

### Markdown の直接編集で文字を拡大・縮小する

- 「直接編集」で `Ctrl + ホイール`，トラックパッドのピンチ，タッチ画面の 2 本指のピンチを使い，文字サイズを変えられる．Mac では `Cmd + ホイール` も使える．
- 設定に表示する 8〜40 px の文字サイズをソース編集と共有する．両ペインへ反映し，選んだサイズを次回の起動にも使う．

### コンパイルした PDF の結果を削除する

- ファイル一覧の「コンパイルした PDF」で項目を右クリックし，「削除…」を選べる．TeX 文書とファイルの件数を確認して「削除」を押す．
- その TeX 文書の過去分を含む PDF と SyncTeX のキャッシュ，コンパイルの出力と補助ファイルを削除する．原稿と，通常のファイルとして保存・コピーした PDF はそのまま残る．
- 表示中の結果を削除した場合は，残る PDF のうち最も新しいものを開き，全てなくなるとプレビューを空にする．TeX 文書を再コンパイルすると，新しい PDF が一覧へ戻る．

### 更新する

原稿を保存して旧版を終了してから，新版を開く．設定，草稿，TeX Live の場所は引き続き使える．Microsoft Store 版は，対応する申請の公開後に更新できる．
