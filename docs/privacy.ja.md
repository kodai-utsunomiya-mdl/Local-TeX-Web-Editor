# Local TeX Web Editor のプライバシーポリシー

更新日: 2026 年 11 月 21 日

[English](privacy.md)

Local TeX Web Editor は，PC にある文書を編集し，PC の TeX でコンパイルするアプリです．原稿をアップロードするサービス，広告，利用状況の解析，自動で送信するクラッシュレポートはありません．アプリ用のアカウントも不要です．

## 原稿と PC に保存するデータ

アプリは，選んだプロジェクトフォルダーの文書を読み書きします．ファイル一覧，アウトライン，引用・相互参照の候補，画像と PDF のプレビューを表示するためにも，プロジェクト内のファイルを読み込みます．コンパイルには PC 上のファイルを使います．

保存や作業の再開のため，次の情報を PC に記録します．

- プロジェクトと TeX の場所，最近開いたプロジェクト，コンパイルの設定．
- 表示言語，テーマ，文字サイズ，自動保存の設定．
- 原稿のファイルへまだ保存していない文章を含む草稿．
- 編集履歴のために圧縮した以前の本文と，入力した版の名前．
- 自分のテンプレートに選んだプロジェクトのファイルと，テンプレートの名前・説明．
- 開いている文書，カーソルの位置，プレビューの表示位置．
- コンパイルした PDF のコピー，SyncTeX のデータ，対応する原稿の情報．
- TeX のセットアップや管理を使った場合は，導入先とその記録，パッケージの情報とログ．セットアップでは，取得した TeX のプログラムとパッケージも保存します．

これらはエディタの動作と前回の作業の再開に使います．アプリを通じて開発者へ内容を送る処理はありません．

設定，草稿，編集履歴，自分のテンプレート，プレビューのコピーは，アプリのユーザーデータフォルダーに保存します．その中の `history` フォルダーに編集履歴，`templates` フォルダーに自分のテンプレートを置きます．Windows の Microsoft Store 版では，そのパッケージの `LocalState` フォルダーを使います．ZIP 版の既定の場所は `%APPDATA%\LocalTeXEditor`，Mac では `~/Library/Application Support/LocalTeXEditor` です．コンパイル中のファイルとログは，プロジェクト内の `.local-tex-editor/build` または TeX の設定で指定した出力先にも書き込みます．

アプリから導入する TeX の既定の保存先は，Windows の ZIP 版では `%LOCALAPPDATA%\LocalTeXEditor\tex`，Store 版ではパッケージ内の `LocalState\LocalTeXEditor\tex`，Mac では `~/Library/Application Support/LocalTeXEditor/tex` です．この下に導入ごとのフォルダーを作ります．セットアップの開始前に，自分のユーザーフォルダー内の別の場所へ変更できます．

Store 版の初回起動時には，既存の ZIP 版にある設定，草稿，表示位置などを Store 版のユーザーデータフォルダーへコピーできます．ZIP 版の元のデータはその場所に残ります．原稿のファイルも，ユーザーが置いた場所にあります．

ブラウザにもテーマの設定を保存します．草稿をアプリのフォルダーへ書き込む間は，ブラウザに一時的な草稿のコピーを置く場合があります．アプリが保存の完了を返すと，そのコピーを削除します．PC 内の接続に使うトークンは，ブラウザタブのセッションストレージに置きます．

## PC 内の通信

起動すると，`127.0.0.1` などの loopback アドレスでサーバーを動かし，同じ PC のブラウザで開きます．編集，保存，コンパイル，プレビューの操作には，この PC 内の接続を使います．ファイルとコンパイルの API へ接続する際には，起動時に生成したトークンが必要です．

エディタのプログラム，フォント，PDF の表示に使うファイルはアプリに含まれています．編集やプレビューのために，これらを外部サービスから読み込む必要はありません．

## TeX の導入とパッケージの取得

TeX のセットアップは，取得元，導入先，パッケージを確認して「ダウンロードしてインストール」を選ぶと始まります．GitHub から公式の TinyTeX の配布物をダウンロードして SHA-256 を照合し，追加の TeX パッケージは CTAN のミラー，または TeX Live の年度に合う過去の配布元から取得します．後でパッケージを追加する際も，内容を確認して開始します．既存の TeX Live，MacTeX，TinyTeX へ追加する場合は，その環境の `tlmgr` に設定された取得先を使います．`tlmgr` が導入済みの年度と CTAN の現行年度の不一致を報告した場合は，導入済みの年度の公式 `tlnet-final` へ再試行し，環境に保存された取得先の設定はそのまま使います．独自の取得先，ローカルの取得先，複数の取得先が設定された場合は，その設定で実行します．オンラインの配布元からのダウンロードにはインターネット接続を使い，通常の原稿の編集には前述の PC 内の接続を使います．

取得先には，IP アドレスと，取得する配布物やパッケージのパスなど，ダウンロードのための通信内容が伝わります．TeX の導入やパッケージ管理のために，原稿，草稿，PDF，参考文献の内容を取得先へ送信する処理はありません．GitHub の通信には [GitHub のプライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) が適用されます．パッケージの配布元とミラーは，それぞれの運営者と方針に従います．[TinyTeX の配布ページ](https://github.com/rstudio/tinytex-releases/releases/tag/v2026.11) と [CTAN のミラー一覧](https://ctan.org/mirrors) で取得先を確認できます．

パッケージの案内画面では，ターミナルに入力するコマンドも用意できます．実行すると，指定された TeX の配布元へ接続します．導入済みのパッケージの一覧と削除の確認には，PC にある導入先の情報を使います．アプリから公式の TeX 管理ツールを開いた場合は，そのツールの取得先と通信の設定が使われます．

他のアプリと共用する TeX を変更する際には，OS の承認が必要な場合があります．承認画面は Windows または macOS が表示し，このアプリが管理者のパスワードを求めたり受け取ったりすることはありません．Store 版では，管理者権限が必要な操作には既存の公式 TeX 管理ツール，または Windows のアプリ設定を開きます．

## 外部リンクと他のソフトウェア

文書やヘルプにある外部リンクを選ぶと，ブラウザでリンク先のサイトを開きます．そのアクセスには，リンク先のプライバシーポリシーが適用されます．Markdown の外部画像はリンクとして表示し，プレビューから自動で取得しません．プロジェクト内の画像は PC から読み込みます．

TeX のエンジン，文献処理のプログラム，プロジェクトで指定したコマンドは，別のプログラムとして動作します．ファイルやネットワークへのアクセスは，それらの設定によります．

OneDrive，iCloud などの同期・バックアップ用のフォルダーへ原稿やアプリのデータを置いた場合は，そのサービスの設定に従ってファイルがコピーされることがあります．

Microsoft Store から導入した場合は，Microsoft が Store のインストールと更新を管理し，[Microsoft のプライバシーステートメント](https://www.microsoft.com/ja-jp/privacy/privacystatement) が適用されます．ブラウザと OS にもそれぞれのプライバシー設定があります．このアプリが Microsoft アカウントの認証情報を求めたり受け取ったりすることはありません．

## データを管理する

原稿のファイルは，普段使うファイル操作で編集・コピー・削除できます．アプリの草稿を確認する画面からは，その草稿を削除できます．設定で自動保存をオン／オフにできますが，PC への草稿の記録は自動保存の設定とは別に行います．

「編集の操作 → 編集履歴を開く → 履歴の設定」で，履歴を保存する日数と容量を変更したり，新しい版の記録を止めたりできます．初期値は 30 日・全プロジェクトで合計 50 MiB で，1 ファイルにつき最大 50 版，全体で最大 2000 版を記録します．2 MiB を超える原稿は履歴の対象外です．上限に達すると，名前を付けた版を含めて古い履歴から削除します．記録をオフにした後も，既存の履歴には同じ上限を適用します．全ての履歴を削除する場合は，アプリを終了してユーザーデータフォルダー内の `history` を削除します．

自分のテンプレートへ登録するファイルは，ユーザーが選びます．「編集の操作 → テンプレートを管理 → 選んだテンプレートを編集する」で名前と説明を変更でき，登録を削除することもできます．テンプレートを削除した後も，元の原稿と，そのテンプレートから作成したプロジェクトは，それぞれのフォルダーに残ります．

設定，草稿，編集履歴，テンプレート，プレビューのコピーを削除する場合は，必要な原稿を保存してアプリを終了し，アプリのユーザーデータフォルダーを削除します．ブラウザのサイトデータの設定からは，テーマや残っている草稿のコピーを削除できます．プロジェクトの原稿や，以前使っていた ZIP 版のデータフォルダーは，それぞれの場所で管理します．

「設定 → TeX を管理…」には，選択中の TeX の環境とパッケージを表示します．アプリから導入した TeX と，既存の TeX Live，MacTeX，TinyTeX が対象です．パッケージは削除する内容を確認してから実行します．アプリ内から環境全体の削除を開始する場合は，実際の保存先と中身，他のアプリへの影響を確認し，フォルダー名を入力します．アプリが導入したファイルの削除，Windows の公式アンインストーラーの起動，選んだフォルダーをごみ箱へ移す操作のうち，使う方法を確認画面に表示します．Store 版で共用の環境を扱う場合は Windows のアプリ設定を開き，Windows 側で削除を選びます．設定画面を開く段階では削除を始めず，アプリでのフォルダー名の入力も不要です．TinyTeX の削除時には，その環境を指す PATH などの登録も解除します．公式アンインストーラーが設定などを残す場合には，そのファイルをアプリのログに表示します．プロジェクトの原稿は，それぞれの保存先で引き続き使えます．

Windows の ZIP 版では TeX を `LocalAppData` に保存するため，`AppData\Roaming` の設定を削除した後もその TeX は残ります．Mac と Store 版では既定の TeX の場所がアプリのデータフォルダー内にあるため，フォルダー全体を削除すると TeX も削除されます．アプリのデータフォルダー外にある既存の TeX は，その場所で管理します．

## 問い合わせとプロジェクトのサイト

紹介ページ，ダウンロード，Issue は GitHub 上にあります．これらを開く際のアクセスは，[GitHub のプライバシーステートメント](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) に従って扱われます．

公開リポジトリの Issue，コメント，添付ファイルとして自分で送った内容は，GitHub に保存され，他の人にも表示されます．報告に含める文章，スクリーンショット，ファイルは，ユーザーが選びます．

アプリのデータの扱いに関する質問は，プロジェクトの [Issue](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor/issues) へ送れます．同じリポジトリで [ソースコード](https://github.com/kodai-utsunomiya-mdl/Local-TeX-Web-Editor) も公開しています．
