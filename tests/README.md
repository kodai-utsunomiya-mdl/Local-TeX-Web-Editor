# Windows と macOS での動作確認

`editor.spec.mjs` は，同梱の `fixtures/japanese` を一時フォルダーへコピーし，配布する実行ファイルを起動する．TeX Live で原稿をコンパイルし，Chromium で編集とプレビューの操作を確認する．

既存の Windows の操作テストでは，表示言語を日本語に指定する．英語のテストは言語を未設定で開始し，英語での保存・コンパイル，日本語への変更，英語に戻して再起動する操作を確認する．言語の変更時にも原稿と PDF の内容，ページ位置と倍率，TeX のログが同じであることを確かめる．

次の操作を確認する．

- 起動時に誤ったアドレスを指定した場合，`--no-browser` では画面の操作を待たず，標準エラーと終了コードを返す．
- 終了の確認を取り消して編集を続け，次に保存して終了した際にタブが閉じることを確認する．
- ブラウザがタブを残した場合に終了画面を表示し，未保存の草稿を次回の起動で戻す．
- 最後のブラウザタブを閉じてもアプリが動作を続け，同じ接続先へ戻れる．CDP でページを frozen にして従来の 5 秒を超えて待ち，復帰後に草稿，編集，保存，再読み込みを確認する．明示的な終了操作でアプリが終了する．
- 長い原稿へ最後に入力した短い変更を，タブを閉じた後の起動で草稿から読み戻す．書き込み中の PUT と終了直前の PATCH が前後しても新しい内容が残ることを確認する．
- 配布する実行ファイルの `--version`，API の `version`，画面に表示するバージョンがリリースと一致することを確認する．
- 配布済みの v0.1.3 を起動し，そのプロセスが動いたまま新版を起動する．移行画面から原稿を保存したことを確認して旧版を終了し，新しい版の編集画面へ進む．旧版はリリースの ZIP を SHA-256 と照合してから使用する．
- 別ファイルの読み込み中に終了の確認を開いて取り消し，元の原稿へ戻って編集と保存を続ける．
- 日本語と空白を含むフォルダーを画面から開く．
- 日本語のコメントを編集して保存する．
- ライト／ダークでエディタと PDF の文字をマウスで選択し，実際の描画画像に選択色が付くことを確認する．エディタでは現在の行，複数行，フォーカスが移った後の表示を扱う．
- 外観のモード・配色・アクセント・フォントを保存し，編集・保存・コンパイルとアプリの再起動後に，選んだ外観と PDF を確認する．テーマボタンでライト／ダークを変えた後も，配色・アクセント・フォントの選択を使えることを確認する．
- 外観の変更をキャンセルや `Esc` で戻し，未保存の原稿と設定画面で選択中のコンパイラーが同じであることを確認する．システムのライト／ダークへの追従と，幅 480 px の画面での外観の操作も扱う．
- ヘルプのボタンと `F1` から操作方法を開き，表示言語に合う使い方・更新・問い合わせのリンクと，環境情報のコピーを確認する．ログや設定への移動，未保存の原稿や設定を編集中の場合，小さい画面から元の操作へ戻る場合も扱う．
- 複数の独立した TeX 文書をタブで開き，編集中の文書をコンパイルする．タブの切り替えだけでは PDF が変わらず，コンパイル後に対象の文書名，PDF，ダウンロード名，SyncTeX が対応することを確認する．前の文書へ戻ってコンパイルした場合は，その文書のページ位置を読み戻す．
- 別の文書のコンパイルが失敗した場合も，直前に成功した PDF を表示する．
- Markdown を開いて編集し，右側の本文，表，コード，数式，相対画像が更新されることを確認する．リンクから別の Markdown を開き，元の文書へ戻る．Markdown を表示している間に TeX のコンパイルが終わった場合も，PDF に戻るとページと倍率が同じであることを確認する．
- Markdown の原稿を Ctrl+クリックし，移動ボタンでもプレビューの対応箇所へ進む．プレビューから原稿への移動，スクロール同期の切替と設定の保存，プレビューの幅が 260 px の時の操作欄，小さい画面での表示切替を確認する．
- プレビューで PDF を選んで Markdown を編集・保存し，PDF のページと倍率が同じであることを確認する．Markdown を選んで TeX をコンパイルした場合は，その Markdown を表示しながら PDF の更新が完了する．「自動」に戻すと，編集するファイルに合わせて表示が変わることを確認する．
- 複数行の TeX をクリップボードから検索欄へ貼り付け，前後へ移動して置換する．TeX の `\` と改行が保存後も同じであることを確認する．
- 空フォルダー，PNG，SVG，PDF をファイル一覧から開き，編集中の原稿へ戻る．カーソルと草稿を確認する．
- 1440 × 900 の画面で，上部の操作欄と原稿・PDF の開始位置を確認する．
- ファイル一覧・アウトラインの幅とログの高さをドラッグと矢印キーで調整し，表示の切り替えやアプリの再起動後に同じ大きさへ戻ることを確認する．ファイル一覧の幅を変えた後も，原稿とプレビューの境界を移動できることを確認する．
- 境界を端まで動かしても原稿とプレビューの操作領域が残り，ウィンドウを縮めると各表示欄が画面に収まることを確認する．幅 260 px の PDF プレビューで，ページ移動・倍率・検索・保存の各操作が枠内に収まることを確認する．ファイル一覧を閉じた時の幅と，モバイル表示でログの高さを変える操作も扱う．
- プロジェクトの `latexmkrc` を読み，upLaTeX，upBibTeX，dvipdfmx で本文と参考文献をコンパイルする．
- PDF の一部を HTTP Range で受け取り，ブラウザで描画する．
- PDF をマウスホイールで続けて読み，倍率と画面のテーマを変更する．
- PDF の倍率を選び，`＋` / `−` で拡大・縮小を繰り返して，プレビュー中央の PDF 上の位置を確認する．`Ctrl + ホイール` では，ポインターの位置にある PDF 上の箇所が同じ画面位置にあることを確認する．
- 設定の文字サイズ，エディタ上の Ctrl + ホイールと 2 点のタッチ操作で原稿を拡大・縮小する．原稿の bytes，PDF の幅・ページ・更新状態，ブラウザ全体の倍率が同じであることを確認する．
- PDF 内の日本語を検索し，そのページを表示する．
- 二ページ目を表示してから再コンパイルし，そのページが引き続き表示されることを確認する．
- 日本語と空白を含む `.tex` のファイル名を使い，SyncTeX で原稿の行から PDF へ移動し，PDF の文章からその原稿を開く．
- 「PDF の位置へ」と原稿の `Ctrl + クリック` の直後に，強調表示の位置と寸法，エラーの有無を確認する．
- 0 / 90 / 180 / 270 度の PDF のページを 75% と 150% で表示し，実際に描画した図形の四辺と強調枠を比較する．図形の中心をダブルクリックした際に返る座標も確認する．
- アプリを起動し直し，前回の PDF と SyncTeX の情報を読み戻す．
- 自動保存でディスクへ書き込み，アウトラインから節へ移動し，参考文献のキーを補完する．
- 自動保存を切った状態で草稿を保存し，アプリの再起動後にその草稿をエディタへ戻す．
- 150 ページの単純な原稿をコンパイルし，末尾へ移動する．ブラウザの canvas の数が 20 以下であることを確認し，その数と画素数を記録する．
- 外部で原稿が変更された場合に，画面の編集内容とディスク上の変更が残り，競合が表示されることを確認する．
- UTF-8 BOM と CRLF を含むファイルを保存する．
- 認証がないリクエスト，異なる Origin，プロジェクト外のパスを拒否する．
- TeX のエラーと終了コードを表示し，エラーの行へ移動する．最後に成功した PDF も表示する．
- 実行中の TeX を停止し，続けて通常のコンパイルを行う．

Windows のワークフローでは [r-lib/actions/setup-tinytex](https://github.com/r-lib/actions/tree/v2/setup-tinytex) で runner に TeX Live を用意し，日本語のパッケージを `tlmgr` で導入する．

Windows の Go テストでは，一時フォルダーでショートカットを作り，リンク先と起動時のフォルダーを読み戻す．実行ファイルの配置と更新，更新先が実行中の場合の応答も確認する．フォルダーの選択画面については，実際にウィンドウを開き，前面への表示，取消，HTTP の切断後に閉じる動作，次回の表示を確認する．

Windows API で配布用の実行ファイルから大小のアイコンを取り出し，埋め込まれた 9 サイズの画像を読み込む．各画像の bytes を同梱の ICO と照合する．既存のショートカットを更新し，同じ実行ファイルのパスでも専用アイコンへ変わることを確認する．

macOS では `scripts/build-macos.mjs` が Apple Silicon と Intel の実行ファイルを含む `.app` を作り，アイコン，バージョン，署名の整合を確認して ZIP に収録する．`scripts/test-macos.mjs` は同じ配布 ZIP を両 CPU の runner で展開し，Launch Services から起動する．ブラウザでの保存，日本語のコンパイル，SyncTeX，別のメイン文書，Markdown，再度開く操作，終了ボタンを使った終了を確認する．OS のフォルダー選択画面も実際に開いて閉じる．

新版の起動時に行う更新について，一時フォルダー内の配置済みアプリと既存のショートカットが変わることを確認する．インストールがまだない場合，別のアプリを指すリンク，外部で変更された実行ファイルも扱う．

## ファイルと文書の操作

`interface-workflow-cases.mjs` は，言語を選択した直後の表示，日英のラベル，保存とキャンセル，すべてのタブを閉じる際の未保存の本文と保存競合，空タブでの再読み込み，長いタブ欄の横スクロールを確認する．

`file-operation-cases.mjs` は，右クリックとキーボードからのファイル操作，名前を変えた後の編集，削除の確認，新規ファイル・フォルダー，プログラムの編集を扱う．Go のテストでは，プロジェクト内のパス，シンボリックリンク，同名ファイル，外部から変更されたファイル，空でないフォルダーを含めて確認する．

`document-tools.spec.mjs` と `document-tools-workflow-cases.mjs` は，新しい Markdown ページと相対リンク，Undo，同名ファイル，PDF の文字を保存する操作，画像のみの PDF，進捗とキャンセルを扱う．Markdown の印刷プレビューでは数式・表・画像を読み込み，実際の PDF もテスト結果へ出力する．

`preview-navigation.spec.mjs` は，幅 240〜820 px の PDF 表示欄で +/− と保存ボタンを常に表示し，拡大・縮小，ページ移動，検索，暗い表示を使えることを確認する．

## 開発環境で実行する

`markdown-preview.spec.mjs` は，Markdown の表示，数式，画像を読む際の認証，画像の再利用，文書内のリンク，テーマ，スクロール位置をブラウザで確認する．原稿の行からプレビューへの移動，段落内のスクロール位置，画像の読み込みや再描画を待っている間の追従も扱う．入力された HTML やプロジェクト外のパスも扱う．`compile-target.test.mjs` は，本文の変更，コメントやコード例，親ファイルの指定からコンパイル対象を選ぶ処理を確認する．

`tex-packages.test.mjs` は，設定済みの TeX を使う追加コマンド，Windows / Mac の引用形式，不足ファイル名から作る検索用の正規表現を確認する．入力されたパッケージ名やファイル名にシェルのコマンドやオプションが含まれる場合も扱う．Go のテストでは，小さめの TeX Live，BasicTeX の symlink，旧年度，不明な年度を含め，表示するプログラムと取得先を確認する．

フロントエンドをビルドした後，実行ファイルを `bin/local-tex-web-editor.exe` に作成する．`LOCAL_TEX_EDITOR_TEST_EXE` で別の場所も指定できる．TeX Live の実行ファイルがある場所は `LOCAL_TEX_EDITOR_TEST_TEX_BIN` で指定する．

```powershell
npm ci
npm run test:unit
npm run build
npm run build:windows-resources
go test ./...
go build -o bin/local-tex-web-editor.exe ./cmd/local-tex-editor
$env:LOCAL_TEX_EDITOR_TEST_TEX_BIN = 'C:\texlive\2025\bin\windows'
npx playwright install chromium
npm test
```

テストの終了時に一時フォルダーを削除する．失敗時は `test-results` にブラウザの画像と trace，アプリの出力を保存する．成功したブラウザの画面も同じ場所へ保存する．GitHub Actions の `local-tex-web-editor-windows-x64` と `local-tex-web-editor-macos-universal` に配布ファイルを保存する．Release への公開は Windows と両 Mac のテストが成功した後に進む．

日本語のコメントの入力は Unicode 文字列を使って確認する．Windows の各 IME の候補選択や変換中のキー操作は，実際の執筆画面でも確認する．
